📖 How It Works

What is CoinLore?

CoinLore provides free cryptocurrency market data via a REST API. No API key or authentication required — just fetch and go.

Quick Start

// Get top 100 coins
const res = await fetch('https://api.coinlore.net/api/tickers/');
const data = await res.json();
console.log(data.data); // array of coin objects

// Get global market data
const global = await fetch('https://api.coinlore.net/api/global/');
const info = await global.json();
console.log(info[0].total_mcap);

// Get specific coin (Bitcoin = id 90)
const btc = await fetch('https://api.coinlore.net/api/ticker/?id=90');
const coin = await btc.json();
console.log(coin[0].price_usd);

Key Endpoints

  • /api/tickers/?start=0&limit=100 — paginated coin list
  • /api/ticker/?id=90 — single coin by ID
  • /api/global/ — global market stats

Rate Limits

CoinLore is free but intended for moderate use. Avoid hammering the API — a 30-second refresh interval works well. Data updates roughly every minute.
