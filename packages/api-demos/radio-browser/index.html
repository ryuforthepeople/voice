📡 How It Works

This demo uses the Radio Browser API — a free, open-source database of internet radio stations. No API key or authentication needed. Just fetch and play!

Key Endpoints

/json/stations/topvote?limit=50
Top voted stations worldwide
/json/stations/search?name=jazz
Search stations by name
/json/stations/bycountry/Netherlands
Filter by country
/json/stations/bytag/rock?limit=50
Filter by genre tag
/json/countries
List all countries
/json/tags?order=stationcount&reverse=true
Popular tags/genres

Code Example

// Fetch top voted stations const res = await fetch('https://de1.api.radio-browser.info/json/stations/topvote?limit=10'); const stations = await res.json(); // Play a station with HTML5 Audio const audio = new Audio(stations[0].url_resolved); audio.play(); // Each station object contains: // { name, url_resolved, country, countrycode, tags, codec, bitrate, votes, ... }
